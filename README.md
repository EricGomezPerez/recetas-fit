# Recetas Fit

Web estática generada a partir de `RECETAS FIT.txt`.

## Incluye
- 50 recetas importadas del archivo.
- Buscador por nombre, categoría e ingredientes.
- Filtros por Desayuno, Almuerzo, Cena, Snack y Postre.
- Favoritos guardados en el navegador mediante localStorage.
- Vista detallada de cada receta.
- Ingredientes, elaboración, tiempos, etiquetas e información nutricional.
- Diseño responsive para móvil, tablet y ordenador.
- Sin backend ni instalación necesaria.

## Cómo usarla
Abre `index.html` en el navegador.

## Cómo publicarla
Puedes subir estos archivos a GitHub Pages, Vercel, Netlify o cualquier hosting estático.
